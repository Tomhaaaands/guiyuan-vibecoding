# R32 - 接入 SiliconFlow 真实后端并通过套件基线

## 结论

- 在 `tools/analysis_provider.py` 注册 `siliconflow` 真实后端（OpenAI 兼容 `/chat/completions`，
  stdlib urllib），默认模型 `Qwen/Qwen3-8B`、base `https://api.siliconflow.cn/v1`。
- API 密钥只从 `VCM_SILICONFLOW_API_KEY` 运行时读取，不进 git；`.gitignore` 追加 `.vibecoding/`，
  本地 provider 配置不可提交。
- `analysis_labels` 的 `similarity` 从 token-set Dice 换成**字符 bigram Dice**（阈值 0.40），
  对模型同义改写更公平；`--mode id/similarity` 保留。

## 实测（金标准套件，字符 bigram 相似度）

| backend | model | aggregate F1 |
| --- | --- | --- |
| `local-fallback` | heuristic-v1 | ~0.207 |
| `siliconflow` | Qwen/Qwen3-8B | ~0.395 |

- 单 case：email-login recall=1.0、f1=0.5；admin-dashboard recall=0.43；ambiguous recall=0.57。
- 模型能产出事实/假设/选项/决策/待确认问题，且不靠复述意图；`local-fallback` 只填两个桶。

## 验证

- `python tools/behavior_harness.py` -> 12/12 pass。
- `analysis_eval --suite ... --provider siliconflow`（真实 API 调用）-> 聚合 0.395 > 基线 0.207。
- `py_compile tools/*.py` -> ok；`check_drift.py` -> 绿。
- 密钥现用即弃、未写入仓库；测试用的 key 只用于本次运行。
