## 实现

1. **改名**：skill 文件夹/触发词 `project-bootstrap` → **`vibe-coding-manager`**
   （`$project-bootstrap` → `$vibe-coding-manager`），显示名 **VibeCoding Manager**，
   版本 1.2.0；仓库源码、templates/assets 副本、`vibe-coding-install` 内嵌包、`$CODEX_HOME`
   全部同步；旧副本移到 `%TEMP%\wcm-rename-backup-*`；CHANGELOG/archive 历史记录不改。
2. **GitHub 端到端**：安装 gh 2.98.0（winget）→ `gh auth login` 设备授权（Tomhaaaands，
   scopes 含 repo）→ 创建私有测试仓 `vibe-coding-e2e-demo` → 用新 skill 接管一个脚本项目
   （`hello.py`）→ `--github` 设 origin → `--push` 自动创建初始提交并推送成功。
3. **e2e 暴露并修复的三个 bug**：
   - `--push` 在全新仓库没有首个提交时直接失败 → 新增 `_git_push` 自动 `git add -A` +
     `git commit -m "chore: init"`（repo-local 身份，无则从 gh profile 取，隐私邮箱回退
     noreply）；
   - `_ensure_git_identity` 检查身份未带 `cwd=target`，误读仓库根目录自身 git 配置而提前
     返回 → 修复为在目标目录内检查 name+email；
   - gh 不在 PATH（标准 Windows 安装路径）→ 新增 `_gh_cmd()` 回退
     `%ProgramFiles%\GitHub CLI\gh.exe`；另修复模板 `.gitignore` 的 `.env.*` 误忽略
     `.env.example`（加 `!.env.example`）。
