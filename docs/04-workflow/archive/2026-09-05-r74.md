# R74 — Size-aware takeover migration

- Date: 2026-09-05
- Scope: existing-project intake and full takeover
- Decision: scan project size and likely data before recommending adoption; large projects are not
  recommended for full takeover.
- Safety: full takeover requires an external migration plan and a second explicit confirmation.
- Evidence: reversible data moves, path-reference hash checks, migration receipts, template records,
  and `.guiyuan-vibecoding/takeover.json` completion marker.
- Verification: focused migration scenario, `python -m tests.run_tests`, `python tools/check_drift.py`,
  and distribution verification.
