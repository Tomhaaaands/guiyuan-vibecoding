# R57 · pb-bridge（2026-09-03）

## Background

P7 的 VCM 侧：定义并实现对归园大管家（PB）的调用桥，接入语义检索，并修复发布包鉴权误报。

## Implementation

- `tools/pb_bridge.py`（项目级工具）：读 `.vibecoding-manager/config.json` 的 `pb_enabled`/`pb_endpoint`，
  暴露 `pb_similarity` / `pb_memory_context` / `pb_memory_result`，经 JSON-RPC（`tools/call`）调用 PB 网关；
  工具名默认映射 `memory_search`/`memory_chat_context`/`memory_write`，可配置。PB 关/不可达/报错均返回 `None`。
- `hydrate.py --semantic`：`HYDRATE_SEMANTIC_BACKEND=pb`（或 `guiyuan_butler`）且 `pb_enabled` 时探测 PB；
  否则把关键词作为可靠兜底（PB 响应结构稳定后再消费）。
- `check_package.py`：把 `tests/`、`tools/fixtures/` 排除出“发布物密钥扫描”（合成测试密钥不属发布物）。

## Verification

- 临时项目：`pb_bridge.config()` 默认 `pb_enabled=False`；PB 关时 `hydrate --semantic` 走关键词；
  PB 开但端点不可达 → “PB similarity unavailable；关键词回退”。
- `check_package.py` 通过（package 门禁修复）；`check_drift` 通过、三载荷同步一致。
