# R17 · extreme-token context contract and deterministic gate（2026-08-31）

> Full iteration record. Not read during normal work; current facts live in NOW and the authority
> contracts.

## Goal

Reduce management-context cost beyond R16 without hiding cost in source-code/tool-output classes or
weakening safety and acceptance evidence.

## Decisions

- Normal work uses zero-history startup: README, changelog, archives, methodology, and unrelated
  modules are excluded unless the task explicitly requires them.
- L0 becomes a 20–80 token pointer card; L1 becomes a 100–600 token field/span slice; L2 defaults
  to exact evidence excerpts instead of full artifacts.
- Continuations are delta-only and reference unchanged context by id/hash.
- The operating target is 1,800 management tokens; 2,500 is a blocking hard ceiling. Safety,
  permission, acceptance, and destructive-operation evidence cannot be truncated to fit.
- Context assembly is deterministic-first and records inclusions, exclusions, cache hits, and
  degradation actions.

## Implementation

- Added the standard-library-only context-budget tool and synchronized it to the reusable template,
  manager skill asset, and installer-bundled asset.
- Integrated startup-budget enforcement into the full drift/pre-commit gate.
- Changed root and generated-project startup contracts from mandatory history reads to NOW-first,
  routed field/span retrieval.
- Updated product-facing README, methodology, context/token contracts, architecture, roadmap, and
  state card.

## Verification

- Root AGENTS + NOW estimate: approximately 1,150 tokens, below the 1,800 operating target.
- All three distributable template copies estimate approximately 700 tokens and match each other.
- Estimator fixtures cover ASCII and CJK; deliberate hard-ceiling overflow exits with status 1.
- Python compilation, generated index, drift/sync gate, skill doctor, and diff whitespace checks
  passed at round close.

## Boundary

The estimator is deliberately conservative and deterministic. Provider-native token usage and the
runtime context compiler remain P2/P8 implementation and evaluation work; this round establishes
the enforceable contract and local regression gate.
