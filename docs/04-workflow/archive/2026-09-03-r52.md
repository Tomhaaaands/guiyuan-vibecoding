# R52 · pb-arch（2026-09-03）

## Background

把“嵌入/向量”从 VCM 里彻底剥离，避免商业化、打包 release 与独立用户被本地模型和向量库绑架。

## Decision

- 嵌入/向量全部归 Private Butler（bge-m3 + 向量库）；VCM 定义 `pb_enabled` 开关：
  `off` 为独立 VCM（零模型、零向量，确定性检索 + LLM provider），`on` 才经稳定接口接入 PB。
- 接口无状态：`similarity(query, texts[])`（按需评分，VCM 不持有向量）、`memory_context`（读）、
  `memory_result`（写）。VCM 不复制项目规格进个人记忆，也不建项目向量库。
- 一个索引一种模型；PB 换模型/索引实现不影响 VCM（双方只依赖契约）。
- runtime 打包边界：managed-project 模板只含项目内迭代/门禁工具；产品循环与 packaging/QA 留
  仓库内部；不加 MCP；本地模型不随 VCM 分发。
