# R53 · serve-status（2026-09-03）

## Background

给单项目状态页补一个“按需”本地小后端：打开页面即起服务、关闭即停，避免常驻监听。

## Implementation

- `templates/iteration-methodology/tools/serve_project.py`：stdlib `ThreadingHTTPServer` 绑
  `127.0.0.1`，默认 8010、端口占用自动后移；`GET /` 提供 `status.html`（缺失先渲染）并注入
  page-close 关停脚本；`GET /api/project` 返回只读快照；`GET /api/render` 重新渲染；
  `POST /api/shutdown` 停止服务；空闲超时（默认 900s）兜底。
- `scripts/serve_status.bat`：双击启动器（`cd` 到项目根后运行服务）。
- 单入口流程：`serve_status.bat` 用 `pythonw` 后台启动 `serve_project.py --no-browser`，服务把实际
  URL 写入 `status.server.url`（已 gitignore），`.bat` 轮询到后由 Windows `start "" <url>` 打开浏览器；
  关闭页面经 `POST /api/shutdown` 停止服务，空闲超时兜底。避免依赖 `pythonw` 下 `webbrowser.open`。
- `render_project_home.py` 新增只读 `snapshot()` 供 `/api/project` 复用。
- 模板 `AGENTS.md` 状态页索引行补充 live 服务入口；README 工具数 26→27。

## Verification

  `POST /api/shutdown` 后进程正常退出。
- `tools/check_drift.py` 通过；`py_compile` 三种载荷副本全部通过。
