# R56 · p9-settings（2026-09-03）

## Background

P9 验收是“在本地界面配置 VCM 并确认式增量迁移”。在既有按需本地后端上补 `/api/settings` 与
`/api/adopt`，页面注入最小“设置/接管”面板，无独立前端工程。

## Implementation

- `serve_project.py` 新增：
  - `GET /api/settings` / `POST /api/settings`：读写 `.vibecoding-manager/config.json`
    （`pb_enabled`、`pb_endpoint`），保存后页面刷新。
  - `POST /api/adopt`：`assess` 走 `bootstrap.py --mode assess --json`（只读门禁，返回匹配分/候选）；
    `adopt` 需 `confirmed: true`，先重跑 assess 写临时评估，再 `--mode adopt --workflow name=mode`
    做增量迁移（含备份/回执）。用户未确认或被门禁拦截时直接报错。
  - `_find_bootstrap`：在项目 `.vibecoding-manager/skills/`、仓库 `skills/`、`VIBECODING_SKILLS_HOME`
    查找 `bootstrap.py`；找不到时给出“安装 skill”引导。
  - 页面注入“设置/接管”面板（设置表单项 + 评估/确认接管按钮）。

## Verification

- 临时项目：`/api/settings` 读出默认 → `POST` 保存 `pb_enabled=true` → 再读回 true（持久化）。
- 无 skill 项目：`/api/adopt assess` 返回“bootstrap.py not found（install the vibe-coding-manager skill）”。
- 页面含“设置 / 接管”面板；关停正常。`check_drift` 通过、三载荷同步一致。
