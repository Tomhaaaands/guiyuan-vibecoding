# R22 · pre-1.0 gate and distribution

## Background

The public version line was reset to `0.1.0` while keeping the earlier `v1.2.0` release as a
historical development snapshot. Existing-project adoption gained a deterministic compatibility
gate: low match pauses with full-takeover / scoped-takeover / defer / abandon choices, and an
existing similar system pauses with keep-map / auto-takeover / abandon choices.

Full takeover archives legacy management overlays under `.vibecoding-manager/pre-adoption/` and
never modifies business code. A Chinese README and release-source policy now put the Agent install
message first, with GitHub authoritative and Gitee as the domestic mirror.

## Verification

- Compatibility assessment reports a match score, level, risks, known systems, and required policies.
- Adopt without a required policy is blocked; defer writes only a decision record; abandon writes nothing.
