# R29 - P2 本地内核：类型化工件库 + 上下文编译器 + 行为评估 harness

## 结论

- 落地 P2 的确定性本地内核，全部标准库、零 Provider 依赖，未改任何既有业务实现。
- 新增 `tools/artifact_store.py`：按权威工件契约（docs/artifact-context-contract.md）以
  `artifact_id` 组织工件，sha256 内容寻址、revision 递增、同内容幂等、前缀名空间→kind
  一致性校验、外键/哈希校验与 CLI。
- 新增 `tools/context_compiler.py`：按阶段策略产出 L0 指针卡 / L1 字段切片，硬预算下
  先降级可选切片为 L0 再丢弃，必需验收/安全证据放不下时抛 `BudgetConflict`，并支持
  delta-only 续传。
- 新增 `tools/behavior_harness.py`：6 场景行为评估（工件库生命周期 / 编译器排除 /
  降级 / 冲突 / 增量 / 分析标签验证与评分），可被将来接 Provider 后的分析对照复用。

## 验证

- `python tools/behavior_harness.py` -> 6/6 pass，退出码 0。
- CLI 临时目录实测：`init / write / list / validate` 一致；`EXECUTION` 编译
  tokens 26 / ceiling 2500，archive 被排除。
- 本轮无模板/介质同步需求；`tools/` 工具不参与现有 4 对副本同步门禁。
