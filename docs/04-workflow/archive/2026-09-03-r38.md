# R38 - P3 生产面：analysis -> 权威工件草稿

## 结论

- 新增 `tools/artifact_generate.py`：把已接受的 `analysis`（known_facts / decisions /
  open_questions）映射成权威工件草稿：
  - `product/<slug>` (product-spec)：acceptance / scope / requirements / open questions；
  - `decisions/<slug>` (decisions)：接受的取舍与约束。
- 产物一律 `draft`（不自动 accepted），`depends_on` 指向源 analysis，以便一致性检查兜底。
- 这是**确定性结构映射**，不新造分析未标注的事实；详细的 prose 生成留给后续（语义）层。
