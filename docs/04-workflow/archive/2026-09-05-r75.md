# R75 — Release update catalog

- Date: 2026-09-05
- Decision: every release preparation refreshes the machine-readable update catalog.
- Catalog: `docs/03-reference/update-catalog.json` records current and historical versions,
  tags, Release URLs, installer assets, checksums, and manifests.
- Gates: `release_prepare.py` updates the catalog before the clean-worktree gate;
  `publish_release.py` verifies catalog/tag/version alignment before GitHub mutation.
- Verification: catalog generation, package checks, drift checks, and release asset validation.
