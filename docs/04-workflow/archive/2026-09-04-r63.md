# R63 · PB 候选语义接口接入

## 变更

- `tools/pb_bridge.py` 及模板/安装载荷副本统一调用 PB 正式 MCP 工具：
  `guiyuan_butler_similarity`、`guiyuan_butler_chat_context`、`guiyuan_butler_capture`。
- `tools/hydrate.py` 及三个发布副本在 `--semantic` 下把候选摘要交给 PB similarity；按
  UTF-8 字节计算 `query + texts` 的 64 KiB 请求预算（最多 100 条、每条摘要受限），避免中文
  字符数与服务端限制不一致。
- PB 关闭、不可达、返回业务错误或 Embedding 不可用时保持确定性关键词回退，不阻塞 VCM 主循环。
- 状态/架构/路线/品牌文档和静态项目主页同步，P7 标记为 PB v1 surface 已实现、等待真实联调。

## 验证与边界

- 通过 VCM 单测与 `check_drift.py` 的本地 fixture/副本一致性验证；发布载荷与模板保持同步。
- 真实 PB/NAS 端点未配置或不可达，不能把 fixture 结果当作生产 bge 联调；待端点可达后运行
  `healthz → initialize → tools/list → capabilities → similarity/context/capture` 顺序。
