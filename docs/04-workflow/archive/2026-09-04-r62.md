# R62 · static-project-home-assets

- **结论**：修复直接打开安装后的 `templates/guiyuan-vibecoding-home.html` 时背景图丢失。
- **原因**：模板 CSS 使用 `assets/...` 相对路径，而安装器原先只把图片放在项目根 `assets/`；从 `templates/` 打开时解析到不存在的 `templates/assets/`。
- **改动**：在模板源目录增加 `templates/assets/taoyuanming-2.png` 与 `taoyuanming-bw.jpg`，通过 `sync_copies.py` 同步到项目模板与安装 Skill 载荷；新增 `_inline_assets()` 邻接目录回归测试。
- **清理边界**：确认 `.preview/` 是视觉预览临时目录（含浏览器 profile / 截图缓存），加入 `.gitignore`，不纳入安装包；未递归删除，避免误删仍需保留的预览证据。
- **验证**：`python -m unittest tests.test_render_project_home`、`python tools/check_drift.py`、`python tools/build_dist.py --verify`。
