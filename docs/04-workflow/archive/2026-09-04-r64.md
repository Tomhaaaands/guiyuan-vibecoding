# R64 · PB 独占嵌入收口

## 变更

- 删除 VCM `analysis_provider.py` 中直连 SiliconFlow `/embeddings` 的 `embed_statements`，
  保留 SiliconFlow 仅作为分析/裁决 LLM provider。
- `analysis_labels.score_labels` 增加不暴露向量的 query-against-text scorer；
  `analysis_eval --mode semantic` 通过 PB `guiyuan_butler_similarity` 计算句子级匹配，按
  PB 的最多 100 条、单条 16 KiB、总计 64 KiB 约束自动分块。
- `pb_bridge.py` 增加 `initialize` → `tools/list` → `guiyuan_butler_capabilities` 发现和
  进程内元数据缓存；`hydrate --semantic`、语义评估在能力不存在时回退/失败闭合，不猜测工具。
- 语义评估严格校验 PB 返回的完整索引/分数数组；异常、缺失或非有限分数一律失败闭合，
  不把协议错误静默当作低分。
- bridge/hydrate/home 的模板、Skill 资产和安装载荷副本保持一致；新增无网络契约测试。

## 验证与边界

- `PYTHONPATH=tools python -m unittest discover -s tests -v` 覆盖远程 scorer 与能力发现 fixture；
  `check_drift.py` 和副本一致性检查必须通过。
- 真实 PB/NAS 端点尚未可达；本轮只证明 VCM 不再持有或调用 BGE 嵌入链路，不能替代生产联调。
