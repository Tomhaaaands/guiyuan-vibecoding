# R59 · Guiyuan naming and lifecycle safety (2026-09-04)

## Background

统一对外命名为 `guiyuan-*`，并落实上一轮确认的三阶段响应协议、Markdown-only 项目识别、安装预检和默认卸载边界。

## Implementation

- 三个 Skill 重命名为 `guiyuan-vibecoding`、`guiyuan-vibecoding-install`、`guiyuan-iteration-close-loop`；同步 Skill 路径、触发词、适配器、模板、发布 ZIP 和当前文档。
- `install_skills.py` 与 bundled installer 增加 preflight、manifest 哈希、无确认卸载；只删除可证明属于 Guiyuan 的 Skill，保留用户修改内容、其他 Skill、插件、项目文件和 Butler MCP。
- 现有项目检测增加 `md-managed`（有 Markdown 管理骨架但没有 Skill），继续走既定 `keep / map / managed` 门禁。
- Skill 与项目模板加入“语义化理解 → 解决方案 → 执行计划”通用请求协议，问题咨询允许使用最小回答计划。
