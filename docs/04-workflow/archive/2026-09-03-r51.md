# R51 · project-status（2026-09-03）

## Background

安装模型是每个项目独立安装 VCM，没有全局中枢。因此把“项目管理界面”收敛为单项目、
零后端方案：每次迭代收口后增量同步一份静态 HTML。

## Implementation

- 新增 `templates/iteration-methodology/tools/render_project_home.py`：只读项目本地权威事实
  （NOW / changelog / roadmap / docs 能力与技术域 / git 只读命令），渲染自包含 `status.html`，
  内嵌 CSS、无外部依赖、不写业务源码、不推远端。
- 默认输出项目根 `status.html`，`--out` / `--rounds` / `--agent` 可调；`/status.html` 加入
  项目模板 `.gitignore`（资产与安装载荷同步）。
- 在 `iteration-close-loop` 五步收口后新增第 6 步“重新生成项目状态页”，并在工具清单登记
  `tools/render_project_home.py`。
- 模板 `AGENTS.md` 索引表新增状态页一行；VCM 仓库根 `.gitignore` 同样加 `/status.html`。

## Verification

- 临时目录骨架项目与“能力/技术域/接管分层/GitHub origin”数据副本各渲染一次，均生成 `status.html`，
  区块与来源指针正确，接管徽标不重复、roadmap 表头无误。
- `tools/check_drift.py` 通过（同步、启动上下文 1685/1800、版本单源）。
