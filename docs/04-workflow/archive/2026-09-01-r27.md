# R27 · intent + uv + generic skill install（2026-09-01）

> Full iteration record. Current facts live in NOW and the authority contracts.

## Goal

把用户旅程从“选项式引导”改为“一句话描述 + 确定性语义判断”，并把 UV 作为多项目 Python
工作的默认引导；同时让 Skill 安装不再隐式写 `~/.codex/skills`，改为用户可选的全局/共享/
项目级安装。

## Decisions

- 空目录脚手架不再给 script/plugin/page/preset 菜单；用户先自由描述，`profiles/intent-map.toml`
  用子串信号加权确定性映射到预设。相同描述会解析到相同 profile；低置信度只追问一句开放问题。
- 新增 `content-site`、`ecommerce`、`admin-dashboard`、`bot` 四个预设，扩展 intent map 覆盖
  常见长尾描述。
- UV 作为默认引导的 Python 工具：`--env auto|uv` 在 `--deps auto` 时优先安装/使用 uv，缺失时
  保留 `python -m venv` 回退；preflight 对用户只讲 Python/Node/git/GitHub CLI，uv 作为可选加速器。
- Skill 安装路径改为显式选择：`--skills-dir` / `VIBECODING_SKILLS_HOME` 表示全局或共享目录；
  `--skill-location project` 默认写入 `.vibecoding-manager/skills/`；`--discover` 只读列出已知
  Agent skill 候选。脚手架不再自动写 `~/.codex/skills`。
- `agents/openai.yaml` 降级为可选 Codex 适配器，zip 校验以 `SKILL.md` 为通用最小条件。
- 旅程图、SKILL、README、模板、方法论、安装脚本全部同步为当前 Agent/共享/项目级通用表述。

## Implementation

- `bootstrap.py` 新增 `--intent`、`--dry-run`、`--skills-dir`、`--skill-location`、
  `--discover-skills`，并写入 `.vibecoding-manager/scaffold-plan.json` 固定判型结果。
- `install_skills.py`、`vibe-coding-install/scripts/install.py`、`one_click_install.py`
  统一按显式目录 > `VIBECODING_SKILLS_HOME` > Codex fallback 解析安装根。
- `build_dist.py` 不再把 `agents/openai.yaml` 当作通用安装成功条件。
- 模板 AGENTS.md/README 把 close-loop 的触发方式改成“客户端支持 skill 时使用，否则读取
  项目内副本并运行确定性脚本”。

## Verification

- `--dry-run` 对“Chrome 插件”“SaaS 后台”“电商小程序”均返回稳定 intent 计划。
- `--discover-skills` 只读列出 Codex/Claude/Cursor 候选。
- `sync_copies.py` 同步分发副本；`check_drift.py` 通过。
- 临时目录 scaffold 验证通过；本轮未重建发布 zip。

## Boundary

- Workbuddy/豆包等未公开全局 skill 路径的客户端继续依赖用户选择或项目级安装，不伪装统一路径。
- intent map 是确定性第一层；LLM 语义扩展仍留作后续可选增强，不能直接决定最终 profile。
