# R26 · proxy-primary domestic mirror

## Background

A normal-browser test reported `Access denied` for the Gitee raw URL, while both `gh-proxy.com`
and `ghfast.top` succeeded. The domestic install order is now proxy-first and Gitee raw is no
longer an install source.

## Verification

- Both proxy URLs download the `0.1.0` ZIP and `.sha256` successfully.
- Proxy ZIP hashes match the official SHA-256.
- Docs and install skill no longer point users to Gitee raw.
