# R40 - P5 执行/验证/回执闭环

## 结论

- 新增 `tools/receipt_loop.py`：把派发任务接到带证据的交付结果——
  `checks -> verdict(pass|fail|blocked) -> receipts 工件 -> task 状态 -> project-state`。
- 全部 check 通过 -> `pass`（task=done，stage=DELIVERY，next 用 task_graph 重算）；有失败且
  `retry>0` -> `fail`（task=in_progress，保留失败证据）；无预算 -> `blocked`（task=blocked + blocker）。
- 回执按 revision 存储且幂等（同 checks 复用，不重复执行）；`project-state` 随任务完成同步。
- `task_graph.next_task` 修正为跳过 `blocked`，避免自动派发阻塞任务。
