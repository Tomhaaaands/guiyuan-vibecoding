# R35 - 句子粒度金标准 + 语义门禁转正

## 结论

- 五套金标准全部改为**句子粒度**（完整、自包含的表述），匹配真实分析产出的粒度。
- 这修复了语义度量的关键缺陷：此前短关键词 gold 与长模型句做 bge-m3 余弦会被稀释，导致
  `semantic` 反而反向（0.134 < local 0.141）；句子粒度 gold 后 `semantic` 正确分开。
- 关键发现：词法 char-bigram 在句子粒度 gold 上**不可靠**——`local-fallback` 通过把整句意图
  塞进 known_fact 拿到约 0.418，掩盖真假。因此默认门禁从 `similarity` 切到 `semantic`。

## 实测（5 套金标准，bge-m3 余弦 · 阈值 0.7）

| backend | aggregate F1 |
| --- | --- |
| local-fallback | ~0.169 |
| siliconflow (Qwen/Qwen3-8B) | ~0.299 |

默认门槛 `--min-f1 0.25`：local-fallback exit 1，siliconflow pass。

## 验证

- `analysis_eval` 默认 `--mode semantic --min-f1 0.25`；local-fallback 语义 exit 1（0.169 < 0.25）。
- `behavior_harness.py` 13/13；`py_compile` ok；`check_drift.py` 绿；密钥 0 命中仓库。
- 语义评分需要嵌入提供方（当前 SiliconFlow `BAAI/bge-m3`）；本地 bge-m3 可作为后续无钥匙精确门禁。
