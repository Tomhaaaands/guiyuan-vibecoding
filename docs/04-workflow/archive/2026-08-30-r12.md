# R12 · gate（2026-08-30）

## 背景

把文档纪律从"契约"（写了要跑）升级为"闸机"（不跑就提交不了）：给脚手架项目默认装
pre-commit 门禁，提交前强制 `tools/check_drift.py`。

## 实现

1. 模板新增 `scripts/hooks/pre-commit`：sh 脚本，自动找 python3/python，跑项目
   `tools/check_drift.py`；失败打印 `[gate] check_drift failed` 并 exit 1
   （绕过方式：`git commit --no-verify`）。
2. 模板新增 `scripts/install_hooks.py`：幂等复制 hook 到 `.git/hooks/pre-commit`。
3. `bootstrap.py`：`git init` 成功后自动安装闸机（`_install_precommit_gate`）。
4. 模板 AGENTS.md 技术约束补一条：pre-commit gate 默认运行。
5. 同步：templates ↔ assets/project、vibe-coding-install 内置副本、$CODEX_HOME 安装副本。

## 验证

- kit 自身与 suanming_os 均安装闸机；
- 拦截：docs 下含 TODO 的提交被拒（check_drift 1 issue，exit 1，输出 `[gate] check_drift failed`）；
- 放行：干净提交通过。
