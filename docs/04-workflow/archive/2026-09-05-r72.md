# R72 — GitHub installer asset boundary

- GitHub Release 发布前对安装 ZIP 做同一套单入口校验：manifest 只声明 `guiyuan-vibecoding`，
  `.sha256` 与 ZIP 内容一致，根目录无 install/close-loop 独立目录或嵌套 `SKILL.md`。
- `publish_release.py` 在 dry-run 和真正发布前都执行该校验；不合规资产不会触发 GitHub 写操作。
- 文档明确区分命名安装 ZIP 与 GitHub 自动附带的 Source code 源码快照，避免把仓库兼容源码
  误当成可发现 Skill 安装入口。
- 验证：发布资产校验、分发包 verify、漂移检查与安装/模板/交付定向测试通过。
