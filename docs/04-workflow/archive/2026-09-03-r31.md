# R31 - 分析门禁做真：金标准套件 + 相似度打分 + 红队场景

## 结论

- `score_labels` 增加 `mode="similarity"`（token-set Dice，0.5 阈值），不再要求生成端复刻
  fixture 的 id，真实 Provider 的同义改写也能被公正评分；`mode="id"` 保留给精确回归。
- 新增 `tools/fixtures/analysis/` 三套金标准（email-login / admin-dashboard / ambiguous-make-faster）。
- `analysis_eval` 支持 `--suite` 聚合与 `--mode`，按整体 F1 决定后端是否可上线；当前确定性
  `local-fallback` 对套件约 0.0，成为真实后端必须超越的诚实基线。
- harness 新增 5 个红队场景（空意图 / Provider 失败降级 / kind 错配 / 缺引用 / 相似度评分
  可区分好坏），总数 12。

- `python tools/analysis_eval.py --suite tools/fixtures/analysis --min-f1 0.0` -> 三 case 各
  f1=0.0、聚合 0.0（预期，作为基线）。
