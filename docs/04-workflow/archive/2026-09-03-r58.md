PB 侧已发布唯一权威公共 API 契约 `private_butler/docs/api-contract.md`（v1）。VCM 桥从“猜测接口”
改为“以该契约为准”。

## Alignment

- MCP 传输：`POST <pb_endpoint>/mcp`，JSON-RPC `tools/call`；鉴权 `Authorization: Bearer <pb_token>`
  （配置 `pb_token`，也读 `VCM_PB_TOKEN` 环境变量）。
- 健康探活：`GET <pb_endpoint>/healthz`（无需 token），根路径 `/` 无健康语义。
- 工具名：`guiyuan_butler_chat_context`（背景上下文）、`guiyuan_butler_capture`（幂等结果回流）；
  不再使用 `memory_search`/`memory_write` 等别名。
- `similarity(query, texts[])` 在 PB api v1 **未实现**：`pb_similarity` 直接返回 `unavailable`，
  不伪造 `guiyuan_butler_search` 等价；VCM 走关键词降级。
- 状态页 `/api/project` 的可达性探测、`/api/settings` 配置（增加 `pb_token`）、
  `settings/prd.md`、`guiyuan-brand.md` 均同步为契约口径。
