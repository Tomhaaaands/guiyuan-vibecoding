# R34 - 分析阶段红线强制

## 结论

- `tools/analysis.py` 新增红线强制：从 `red-lines.md`（根）或
  `docs/00-system/constitution/red-lines.md`（旧布局）读取项目红线。
- 采用**保守的话题命中升级**：任何与红线主题重合的 `decisions`/`options`（字符 bigram Dice
  >= 0.25）都会移出确认项，转成 `open_questions` 让用户裁决，并记录 `red_line_touch`。
- 关键发现：词法（token/bigram）**不能区分「遵守」还是「违反」**约束（正确决策 0.382 甚至
  高于违规 0.286），因此只做话题检测、宁问勿放，绝不静默接受敏感决策。
- 红线哈希并入幂等键：项目红线变更会触发重新分析，而非命中旧结果。
