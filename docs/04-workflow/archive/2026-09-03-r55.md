# R55 · status-monitor（2026-09-03）

## Background

让状态页直接回答“这个目录有没有被 VCM 接管”“有没有被 PB 赋能”，并就地给启用引导。

## Implementation

- `render_project_home.py` 顶部新增“接入状态”面板：
  - VCM 接管：已/未（接管时展示 `startup/state/ledger/methodology/tooling` 分层）；未接管给引导。
  - PB 赋能：读 `.vibecoding-manager/config.json` 的 `pb_enabled`/`pb_endpoint`；启用时对 `pb_endpoint`
    做 2 秒可达性探测（`已连接/不可达`）；未启用给“如何开启”的引导。
- `snapshot()` 与 `/api/project` 暴露 `pb`（enabled/endpoint/reachable）。
- 新增 macOS/Linux/NAS 启动器 `scripts/serve_status.sh`（`nohup` 后台 + 服务自己开浏览器 + 页面关闭即停）。

## Verification

- 临时项目：默认 PB 关 → `接入状态/PB 未启用/引导` 正常、无网络调用不卡；`pb_enabled=true` + 不可达端点
  → `已启用 · 不可达`；`/api/project` 返回 `pb` 正确；`/api/shutdown` 正常。
- `tools/check_drift.py` 通过；三载荷同步一致。
