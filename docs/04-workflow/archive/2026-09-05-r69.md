# R69 — secure git and release loop

## 结论

- scaffold/adopt now composes a common `.gitignore` baseline with topology, scale, capability,
  and custom profile overlays; existing user rules are preserved.
- `tools/git_safety_gate.py` scans the staged snapshot and fails closed on secrets, sensitive names,
  caches/build output, unsafe links, oversized files, unapproved binaries, and archives.
- The gate runs before drift in the distributed pre-commit hook and in GitHub Actions; `run_qa.py`
  includes it as a blocking delivery gate.
- `release_prepare.py` builds and validates versioned installer assets. `publish_release.py` is
  dry-run by default and, when explicitly enabled, creates one tag/one Release and verifies assets
  and installer hash remotely.
- 207 tracked cache/release artifact files were removed from the Git index; local files are retained.

## Evidence

`python tools/run_qa.py` and `python tools/check_drift.py` are the close-out commands. A live
GitHub publish was intentionally not repeated for the existing `v0.1.1` release.
