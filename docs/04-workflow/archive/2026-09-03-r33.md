# R33 - 语义打分 + 5 套金标准 + 正式门槛

## 结论

- `analysis_labels` 新增 `semantic` 打分（bge-m3 嵌入 · 余弦 · 可配置阈值）；`analysis_eval`
  支持 `--mode id|similarity|semantic` 与 `--threshold`，语义打分走 SiliconFlow `/v1/embeddings`。
- 实测得出结论：短金标准 + 长模型句时，embedding 余弦（阈值 0.7）反而**分得更差**（siliconflow
  0.134 < local-fallback 0.141），因长句稀释余弦；**字符 bigram 干净分开**（0.429 vs 0.204）。
- 因此默认门禁 = `--mode similarity` + `--min-f1 0.30`；`semantic` 保留为可选、标注为实验
  （需同粒度金标准）；报告了该局限与使用前提。
- 金标准扩至 5 套（新增 api-contract、content-site）。`analysis_eval --min-f1` 默认改为 0.30。
