# R24 · Gitee anonymous raw mirror

## Background

Gitee Release attachments are documented as downloadable by logged-in visitors. To support
non-logged-in users, the mirror moved to repository raw files under `releases/0.1.0/`. The ZIP,
SHA-256, and manifest are tracked in the repo and served through the raw URL used by the install
message.

## Verification

- Package rebuilt with the raw mirror URL and `python tools/build_dist.py --verify` passes.
- `releases/0.1.0/` contains the same ZIP, SHA-256, and manifest as `dist/`.
- GitHub and Gitee Release artifacts replaced with the rebuilt package.
- Browser verification of the raw URL remains external/device-dependent.
